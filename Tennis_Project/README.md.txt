# Tennis Analytics Dashboard

## Project Overview
This project is an end-to-end Tennis Analytics Dashboard built using Python, MySQL, and Streamlit.

## Technologies Used
- Python
- MySQL
- Streamlit
- Pandas
- SQLAlchemy
- Plotly

## Features
- Dashboard KPIs
- Competition Analysis
- Competitor Search
- Country Filter
- Rankings Dashboard
- Interactive Charts
- CSV Download

## How to Run

1. Install dependencies:
   pip install -r requirements.txt

2. Run:
   streamlit run app.py
